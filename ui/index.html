Avisos de novos imóveis

Os avisos chegam mesmo com a janela fechada, enquanto o Radar estiver aberto perto do relógio. Ative a busca automática em Minha busca para receber novidades sem consultar manualmente.

O Windows pode silenciar avisos no modo Não perturbe ou nas configurações de notificações. Os resultados continuam salvos em Avisos.

Avisos dos favoritos

Os favoritos são acompanhados mesmo fora dos filtros de Minha busca. As opções são salvas automaticamente. O aviso de preço compara o lance da mesma etapa e data; os lembretes são enviados uma vez por etapa e data, inclusive se você favoritar dentro do prazo escolhido.

Ative as buscas automáticas para manter os dados atualizados. Lembretes usam leituras do site feitas nas últimas 48 horas. Mudanças de data e situação são verificadas nas consultas aos sites. A primeira leitura serve de referência; falhas de consulta não significam suspensão ou cancelamento. Confira o edital.

Iniciar com o Windows

Consultando a configuração…

Ao entrar na sua conta do Windows, o Radar ficará em segundo plano, no ícone perto do relógio. Dê dois cliques no ícone ou use o atalho da área de trabalho para abrir a janela. Desativar esta opção não fecha o Radar que já está aberto.

Se você desativou o Radar em Configurações do Windows → Aplicativos → Inicialização, reative-o também por lá. O Windows pode demorar um pouco para iniciar os aplicativos.

Buscas em segundo plano

O computador precisa estar ligado, sem suspensão e com internet. Para parar agora, use Encerrar programa. A opção acima controla apenas a próxima entrada no Windows.

SUAS PREFERÊNCIAS
O que você quer encontrar?
Preencha apenas o que for importante. Os campos em branco não limitam a busca.


Localização e tipo
    Escolha uma sugestão. Para adicionar outra cidade, digite ponto e vírgula. As sugestões seguem os estados preenchidos.
      Ex.: São Paulo ou SP. Para vários estados, separe por ponto e vírgula. Em branco, inclui todo o Brasil.
      

      Valor do lance
      Digite o valor em reais: 1000000 vira 1.000.000,00. Para informar centavos, use a vírgula.
      

      Quando será o leilão?
      

      Preço, desconto e data precisam ser atendidos na mesma etapa do leilão. Salvar os filtros reorganiza os dados salvos; use Buscar novidades para consultar os sites.
      Sugestão baseada na sua planilha original. Confira os valores antes de salvar; eles não são limites obrigatórios.
      

      Buscar automaticamente
      A busca se repete enquanto este programa estiver em execução e o computador estiver ligado. Fechar a aba não encerra o programa; o botão Encerrar programa interrompe as buscas.
      Para retomar as buscas ao entrar no Windows, ative Iniciar com o Windows em Configurações. Não é necessário manter o Excel aberto.

      1. Abra o imóvel no site do leiloeiro.
      2. Selecione e copie o texto visível da página.
      3. Cole o link e o texto abaixo para atualizar os dados salvos.
      

      PASSO A PASSO
      Como usar o Radar
      Três passos para começar
      1. Escolha sua busca. Em Minha busca, preencha cidade, valor ou data. Você pode deixar tudo em branco.
      2. Clique em Buscar novidades. Aguarde a conclusão. Cada site pode levar algum tempo para responder.
      3. Veja os anúncios ou abra a planilha. Clique em Ver detalhes para consultar todas as etapas do leilão e acessar o anúncio original.
      

      Dúvidas comuns
      Como salvar anúncios nos favoritos?
      Clique em ☆ Favoritar no anúncio ou nos detalhes. Abra Favoritos no menu para ver sua seleção. Clique em ★ Favoritado para retirar da seleção; o anúncio continua em Imóveis acompanhados. Os favoritos ficam salvos neste computador, inclusive após novas buscas e atualizações do programa.
      Como atualizar a planilha?
      Feche o Excel antes de buscar novidades. A planilha é recriada ao final da busca. O botão Atualizar planilha usa somente os dados já salvos. Abra novamente o arquivo para ver as mudanças.
      Posso escrever anotações na planilha?
      A atualização recria as abas. Para manter suas anotações, use Baixar cópia e salve uma versão separada.
      O que significa “Precisa de conferência”?
      O site pode ter bloqueado a consulta, mudado a página ou deixado informações incompletas. Os dados anteriores continuam salvos. Top e Krobel precisam de texto copiado do navegador; a Superbid está sem consulta automática disponível.
      Qual preço aparece na lista?
      É o lance da próxima etapa com data conhecida, a partir de hoje. Todas as etapas aparecem em Ver detalhes. Uma data futura não confirma que o imóvel ainda está disponível.
      Não encontro nenhum resultado.
      Escolha Todos os anúncios salvos na lista. Se eles aparecerem, revise os filtros em Minha busca. Confira também a situação dos sites.
      A planilha não abre ou não atualiza.
      Feche o arquivo no Excel e tente Atualizar planilha. Se a abertura falhar, use Baixar cópia. A geração depende dos componentes disponíveis neste computador; em outro computador pode ser necessária configuração adicional. Os anúncios continuam disponíveis aqui.
      Posso fechar o navegador?
      Sim. As consultas em andamento continuam. Para encerrar também a repetição automática, clique em Encerrar programa. Seus dados ficam salvos.
      Como abrir novamente?
      Dê dois cliques em ABRIR RADAR.vbs. Se o Windows não executar esse arquivo, use INICIAR.cmd. O programa abre no seu navegador e usa os dados desta pasta.
      

      Se precisar de ajuda
      Informe o que tentou fazer e a mensagem que apareceu. O programa registra os detalhes do erro no arquivo ajuda-tecnica.log, dentro da pasta data. Não apague a pasta data: ela guarda seus anúncios e o histórico.
      

      Os dados refletem a última consulta de cada anúncio. Confira a disponibilidade e as condições no site do leiloeiro.
